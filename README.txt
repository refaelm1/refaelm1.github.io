צ׳ק-ליסט קצין תורן: חבילת אפליקציה

מה בחבילה
- index.html: האפליקציה עצמה. אפשר לפתוח אותה גם לבד, בלי כל שאר הקבצים.
- manifest.webmanifest, sw.js, icon-*.png: הקבצים שמאפשרים התקנה כאפליקציה ועבודה בלי חיבור לרשת.

פרטיות
- האפליקציה לא שולחת שום מידע לשום מקום ולא פונה לכתובות חיצוניות.
- כל הנתונים נשמרים בדפדפן של המכשיר שבו נעשה בהם שימוש, ואינם עוברים בין מכשירים.
- שרת האירוח (אם יש) מחזיק רק את הקבצים האלה, בלי נתוני משמרת.

דרך 1: בלי אירוח (הכי פשוט)
1. מעבירים את הקובץ index.html למכשיר (למשל במייל לעצמך) ופותחים אותו בדפדפן.
2. הנתונים נשמרים בדפדפן. כדאי לפתוח תמיד באותו דפדפן.
הערה: בדרך הזו אין התקנה כאפליקציה עם אייקון, והיא פחות נוחה באייפון.

דרך 2: התקנה כאפליקציה (דורשת כתובת אינטרנט)
צריך להעלות את כל קבצי התיקייה לכתובת שמתחילה ב-https. אפשרויות:
- גורם המחשוב או אבטחת המידע בארגון: מעלה את התיקייה לשרת פנימי. זו הדרך המומלצת לשימוש בעבודה.
- שירות אירוח חינמי לקבצים סטטיים, כמו GitHub Pages או Netlify. מעלים את התיקייה כמו שהיא. השלבים בכל שירות משתנים מדי פעם, ולכן כדאי לפעול לפי ההוראות באתר שלו.
אחרי שהכתובת פעילה:
- אנדרואיד (Chrome): תפריט, ואז "התקן אפליקציה" או "הוסף למסך הבית".
- אייפון או אייפד (Safari): כפתור השיתוף, ואז "הוסף למסך הבית".
- מחשב (Chrome או Edge): סמל ההתקנה בשורת הכתובת.
אחרי ההתקנה האפליקציה עובדת גם בלי קליטה.

גיבוי
- הכפתור "הורד גיבוי משמרת" שומר קובץ טקסט עם כל נתוני המשמרת. הוא זמין עד 16 שעות מתחילת המשמרת.
- קובץ הגיבוי הוא טקסט פתוח. יש להחליט איפה שומרים אותו ומתי מוחקים אותו.

הערה
התבנית כללית ואינה מחליפה את נהלי המשטרה והנחיות המחוז. לפני שימוש בעבודה כדאי לוודא מול הגורם הממונה שמותר להשתמש בה.
